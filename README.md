# Projekt FOOD4STUDENTS
## - Gute Noten für deinen Teller, kleine Preise für dein Konto

## Description
Food4Students ist eine Website wo man gute Restaurants finden kann. Man kann Restaurants nach Namen suchen oder nach Küche. Man bekommt dann verschiedene Empfehlungen von Restaurants, die passen könnten. Wenn ein Restaurant probiert wurde, kann man ein Like oder Dislike als Bewertung hinterlassen.
